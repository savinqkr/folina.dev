## 화면과 선택 상태

책장 생성 버튼 → 생성 화면 → 뒤로 가기로 책장에 복귀합니다. 넓이 900pt 이상에서 왼쪽 흰 옵션 패널·오른쪽 컬렉션색 미리보기 패널을 배치합니다. 좁은 창에서는 미리보기·옵션을 세로로 배치하고 스크롤합니다. 기존 색상·서체·간격·기본 버튼을 재사용합니다.

| 항목 | 제공 선택지 / 초기값 |
|---|---|
| 이름 | 텍스트 입력 / 빈 값은 미리보기에 ‘나의 다이어리’ 표시 |
| 기록 방식 | 날짜형 다이어리(기본), 자유 기록형 다이어리, 자유 스크랩북 |
| 제본 | 링 바인더(기본), 하드커버 노트, 일반 제본형 노트 |
| 색상 | 세이지(기본), 슬레이트 블루, 라벤더, 크라프트, 코코아 + 컬러 피커 |
| 표지 스타일 | 기본형(기본), 식물 창 장식 — 사용자 확인 |
| 속지 | 무지(기본), 줄노트, 모눈, 도트 |
| 방향 | 세로(기본), 가로 |

페이지 크기 정책은 docs에서 미확인입니다. 사용자가 추천안에 동의하여 실제 용지 규격과 크기 선택 없이 화면 내 비율만 사용합니다. 날짜 범위·페이지 개수·불렛저널·추가 템플릿 옵션은 만들지 않습니다.

## 실시간 미리보기

`DiaryDraft`의 필드를 각 옵션에서 변경하면 펼친 미리보기와 표지 썸네일, 현재 선택 설명이 함께 갱신됩니다. 기록 방식·제본·표지·속지는 독립 필드로 다른 옵션 변경 시 유지됩니다.

- 색상: 펼친 다이어리의 바깥 표지와 표지 썸네일에 반영합니다. 사용자 피드백으로 박스·색상 이름을 없애고 동일 크기의 원형 대표 색상과 시스템 컬러 피커를 배치했습니다. 선택 원은 테두리·체크로 표시하고 색상 이름은 VoiceOver에 제공합니다. 직접 선택한 불투명 sRGB 색상은 두 미리보기에 반영하며 대표 색상을 누르면 사용자 색상을 해제합니다.
- 제본: 링 바인더는 금속 링·중앙 금속 책등, 하드커버는 홈·리본, 일반 제본은 얇은 중앙 홈으로 구분합니다. 표지 썸네일은 기존 제본 표현을 사용합니다.
- 방향: 페이지의 가로·세로 비율을 바꾸며 종이 무늬는 회전하지 않고 새 크기에 맞춰 그립니다. 표지 썸네일 비율도 함께 변경합니다.
- 속지: 두 페이지에 무지·가로선·격자·점 패턴을 Canvas로 그립니다.
- 표지 스타일: 기존 `DiaryCoverDecoration`의 기본형·식물 창 장식을 표지 썸네일에서 확인합니다. 열린 속지에는 표지 장식을 겹치지 않습니다.
- 이름: 표지 썸네일 옆과 접근성 설명에 반영합니다. 기존 링바인더 표지의 손글씨 라벨에도 반영합니다.

이 화면은 선택 결과의 외형만 보여 줍니다. 날짜형의 달력 생성이나 기록 방식별 편집 기능은 없습니다. 종이 단면·뒷표지·그림자로 깊이를 표현하며 외부 3D 라이브러리는 사용하지 않습니다.

| 항목 | 원본 | 이번 구현과 근거 |

| 초기 미리보기 | 달력 2페이지·메모 장식 | 선택한 무지(기본) 및 패턴 속지, 달력·메모 추가 안 함 |
| 추가 옵션 | 이름·색상·표지 스타일·방향 없음 | 이번 요청의 선택 영역 및 표지 썸네일 추가 |
| 제본 에셋 | SVG 링 그림자·금속 반사 | 다운로드 403으로 확보하지 못함. SwiftUI 기본 그래픽 활용 요청에 따라 기존 `MetalBinderRing`을 공유; 원본과 차이 있음 |
| 크기·레이아웃 | 고정 1180×820, 패널 495/593×550 | 옵션 증가에 맞춘 스크롤과 적응형 높이·폭; 펼친 다이어리 529×332 구도 기반 |

원본 Figma를 수정하지 않았습니다. 실제 결과 스크린샷과 원본의 시각 비교는 Linux에서 수행하지 못했습니다.

## 저장 제한과 후속 연결

현재 저장·책장 등록·필기/다꾸 편집기·페이지 조작·동기화·로그인·마켓은 없습니다. ‘다이어리 만들기’는 ‘저장 기능 준비 중’ 알림만 표시합니다. 알림을 닫으면 현재 선택을 유지하고, 뒤로 가면 초안을 폐기합니다.

후속 작업에서 확정된 페이지 규격·날짜 정책·저장 스키마를 확인한 뒤 `DiaryDraft`를 저장 계층 입력으로 변환합니다. 저장 성공 후 책장 데이터를 갱신하고 이동해야 합니다. 미리보기 투영인 `DiarySummary`를 저장 완료 데이터로 취급하지 않습니다.

## Mac Xcode 검증

1. Xcode 16.2 이상에서 `FOLINA.xcodeproj`를 열고 `FOLINA` 스킴과 iPadOS 18.2 이상 iPad 시뮬레이터를 선택합니다. 실행에 필요한 SDK와 시뮬레이터를 설치합니다.
2. Product → Build(⌘B), Run(⌘R)으로 책장·깃털 투명 배경·생성 화면 이동을 확인합니다.
3. Product → Test(⌘U)로 `DiaryDraftTests`와 `BookshelfUITests`를 실행합니다. 현재 Linux에서는 미실행이며 통과를 보장하지 않습니다.
4. 유형과 제본을 번갈아 바꿔 선택 유지, 모든 색상·표지 스타일·속지·방향 반영을 확인합니다. 기본·식물 장식 표지와 링·홈·리본, 종이 두께를 Figma와 비교합니다.
5. 세로·가로 회전, 좁은 Split View, 큰 글자 크기, 이름 입력 시 키보드, VoiceOver 선택 표시를 확인합니다.
6. 최종 버튼의 미지원 안내, 닫은 후 선택 유지, 복귀 후 책장 미등록 및 재진입 시 초기화를 확인합니다.

명령줄에서는 `xcodebuild -list -project FOLINA.xcodeproj`와 `xcodebuild -showdestinations -scheme FOLINA -project FOLINA.xcodeproj`로 스킴·실제 기기 ID를 확인한 뒤 다음을 실행할 수 있습니다.

```sh
xcodebuild test -project FOLINA.xcodeproj -scheme FOLINA \
  -destination 'platform=iOS Simulator,id=<확인한 iPad 시뮬레이터 UUID>'
```
