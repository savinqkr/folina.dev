## 원본 접근과 차이

이번 세션에서 두 Figma 화면은 프록시 터널 403, Notion 기능·정책·데이터 모델은 HTTP 403으로 본문을 읽지 못했습니다. 연결된 전용 Figma/Notion 도구도 현재 제공되지 않습니다. 이전 docs의 5차 원본 확인 기록은 보존하지만 이번 변경이 최신 원본과 동일하다고 주장하지 않습니다.

5차 툴바와 FOLINA 테마·상단 헤더를 유지하면서 선택, 텍스트, 사진 버튼 및 하위 속성 영역을 추가했습니다. 원본의 고급 레이어 패널은 이번 범위에서 제외하고 객체 목록 Picker·앞뒤 배치 버튼으로 대체합니다. 폴라로이드·종이 코너는 SwiftUI 기본 도형 합성이며 원본 에셋이나 정확한 수치와 비교하지 못했습니다. Figma 원본은 수정하지 않았습니다.

## 페이지 관리

읽기의 ‘페이지 관리’에서 페이지 목록, 이동 핸들, 추가·복제·휴지통 버튼, 휴지통 복원, 저장 충돌 보호 사본 복구를 제공합니다. 추가·복제·복원·사본 복구 성공 후 해당 페이지를 선택하고 읽기로 돌아옵니다. 정렬은 목록을 유지합니다. 마지막 활성 페이지에는 삭제 버튼을 비활성화하고 이유를 안내합니다. 삭제 전 확인 대화상자를 표시합니다.

## 객체 편집

- 선택 도구: 탭 선택/빈 곳 탭 해제, 드래그 이동, 두 손가락 확대·회전, 우하단 핸들 크기 조절.
- 펜/형광펜/지우개: 객체 hit testing을 끄고 PencilKit 입력만 받습니다. 선택 도구에서는 PencilKit hit testing을 끕니다.
- 텍스트: 삽입 후 선택 속성 영역의 TextEditor에서 한글과 줄바꿈을 편집합니다. 시스템 기본 글꼴의 크기·색상과 상자 크기·회전을 변경합니다. 상자 밖 텍스트 표시는 clip하며 문자열은 잘라 저장하지 않습니다.
- 사진: PhotosPicker로 단일 이미지 선택 → 내부 원본 저장 → 객체 추가. 드래그, 비율 유지 확대·축소, 회전, 일반/폴라로이드/코너 스타일을 제공합니다.
- 공통: 객체 목록 선택, 앞뒤 한 단계 이동, 삭제, 크기 버튼, 15도 회전 버튼과 ‘가운데로’를 제공합니다. ‘가운데로’는 종이 밖 객체도 되찾기 위한 명시적 조작입니다.
- 실행 취소/다시 실행은 기존 필기에만 적용합니다. 선택 도구에서는 필기 Undo 버튼을 비활성화합니다. 객체 Undo와 전체 레이어 패널은 이번에 제공하지 않습니다.

저장·좌표·레이어·파일 정책은 [아키텍처](../architecture/page-decoration.md), 실제 검증 절차는 [체크리스트](../development/page-decoration-verification.md)를 참고합니다.

## 툴바 정리 — 사용자 화면 피드백 반영

첨부된 실행 화면에서 다중 행 속성 UI가 종이 공간을 차지하고 모든 작업이 파란 텍스트로 같은 강조를 받는 문제가 확인되었습니다. 주 툴바는 44pt 도구 버튼의 한 줄 구성으로 정리하고 선택 도구만 진한 배경으로 강조합니다. 펜의 색상·굵기·손가락 입력은 설정 팝오버, 객체의 텍스트/프레임·크기·회전·배치·삭제는 선택 속성 팝오버로 이동했습니다. 확대율은 메뉴로 묶고 저장 상태는 한 문구로 표시하되 접근성 값에는 두 저장소 상태를 유지합니다. 좁은 창에서는 툴바를 가로 스크롤합니다. 사용자 스크린샷과 기존 디자인 시스템을 근거로 한 개선안이며 Figma 원본은 수정하지 않았고, 개선 후 실제 화면과 접근성·키보드/팝오버 동작 검증은 Mac/iPad에서 필요합니다.

## 종이 위 직접 텍스트 입력 — 2026-10-17

선택 도구에서 텍스트 상자를 탭하면 그 자리의 UITextView로 직접 입력·수정합니다. 새 텍스트는 안내 문구를 실제 내용으로 저장하지 않고 빈 문자열로 만들며 바로 키보드를 엽니다. 편집 중에는 객체 이동·확대·회전 제스처를 끄고 커서 이동·한글 조합 입력을 우선합니다. 키보드 위 ‘완료’로 입력을 마치면 다시 드래그로 상자를 이동할 수 있습니다. 속성 팝오버는 글자 설정과 보조 입력에 계속 사용할 수 있습니다.

우하단 조절 원은 지름 12 논리 단위로 줄이고, 44×44 터치 영역의 중심을 상자 꼭짓점에 맞춥니다. 확대 시에는 페이지와 동일한 배율로 표시합니다. 실제 기기 키보드·조합 입력·회전된 상자의 터치 동작과 조절점 위치는 후속 확인이 필요합니다.
