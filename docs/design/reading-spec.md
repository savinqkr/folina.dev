## 확정 요구사항과 구현

책장에서 실제 저장 다이어리를 누르면 기존 정보 화면 대신 읽기로 이동합니다. 샘플은 읽기 대상으로 만들지 않습니다. 제목·현재 위치·책장 복귀, 이전/다음 버튼, 좌우 스와이프, 목차와 책갈피 목록, 현재 선택 페이지의 책갈피 추가/해제를 제공합니다. 편집 버튼에는 ‘편집 준비 중’을 표시하며 안내만 엽니다.

각 페이지의 저장된 속지(무지·줄·모눈·도트), widthMM/heightMM 비율과 연결된 날짜를 사용합니다. 방향은 이미 저장된 가로/세로 치수로 반영하며 화면에 맞추기 위해 비율을 왜곡하지 않습니다. 날짜를 새로 생성하거나 월간 달력·내용·사진을 채우지 않습니다. 현재 생성 정책은 첫 페이지 1개이므로 기존 다이어리는 실제로 한 페이지만 읽을 수 있습니다. 페이지 추가 UI는 이번 범위가 아닙니다.

## 레이아웃과 현재 위치

기기 방향 값 대신 읽기 화면의 실제 창 크기를 사용합니다. 폭 760pt 이상이면서 폭이 높이보다 클 때 양쪽 펼침, 나머지는 한 페이지입니다. 창을 분할하거나 Stage Manager로 줄이면 한 페이지로 전환합니다. 760pt는 제품 원본 정책이 아닌 이번 적응형 UI의 구현 기준입니다.

`DiaryReadingPosition`은 선택한 페이지 UUID를 유지합니다. 펼침은 저장 순서의 1–2, 3–4 식으로 묶지만 선택 UUID를 바꾸지 않습니다. 4페이지를 선택한 상태에서 가로로 전환하면 3–4를, 다시 세로로 바꾸면 4를 보여줍니다. 양쪽 펼침에서는 종이를 눌러 선택하고 선택 위치를 표시합니다. 책갈피는 이 선택 페이지에 적용합니다. 목록에서 페이지를 선택해도 동일하게 동작합니다.

홀수 마지막 펼침의 나머지 슬롯은 투명한 표지 영역이며 페이지 번호·날짜·책갈피를 만들지 않습니다. 페이지가 없으면 안전한 빈 상태를 표시합니다. 첫/마지막 경계를 벗어나는 버튼은 비활성화합니다. 저장 순서는 기존 pages 배열을 정본으로 유지하며 탐색·선택·책갈피의 정체성은 UUID로 관리합니다. 새로운 정렬/재배열 기능은 만들지 않습니다.

## 외형 컴포넌트

`DiaryReadingBook`은 저장 문서를 받아 실제 종이를 배치합니다. `DiaryReadingPaper`는 종이/선택, `ReadingBookCover`는 표지·종이 단면, `ReadingBookSpine`은 제본 외형을 담당합니다. 종이 무늬 `DiaryPaperSurface`와 `MetalBinderRing`, 테마·표지 색상은 기존 생성 화면과 공유합니다. 제본은 기록 유형/날짜와 독립적입니다.

| 제본 | 표현 |
|---|---|
| 링 바인더 | 중앙(한 페이지에서는 왼쪽) 금속 레일, 7개 금속 링, 접촉 그림자와 홈 |
| 하드커버 | 두꺼운 표지 테두리, 내려온 종이 단면, 넓은 접힘과 음영 |
| 일반 제본 | 얇은 표지·종이 묶음, 좁고 약한 중앙 제본선 |

저장 열거형의 스프링도 안전하게 링 계열로 표시하지만 생성 선택지는 기존 세 종류를 유지합니다. 외부 라이브러리·3D 엔진은 없습니다.

## 페이지 전환

스와이프 종료 한 번당 이동 한 번만 요청합니다. 수평 이동이 수직 이동의 1.4배 이상인 경우에만 넘깁니다. 0.24초 좌우 이동+페이드 전환이며 애니메이션이 끝날 때까지 중복 입력을 막습니다. 동작 줄이기 설정에서는 애니메이션을 생략합니다. 실제 종이 말림·물리 시뮬레이션은 구현하지 않았습니다. 자연스러움과 입력 잠금은 Mac에서 검증해야 합니다.

## Figma 확인 및 차이

연결된 Figma 도구로 `03 · 읽기 / v5 확장형 실물 다이어리`, 1180×820 프레임과 스크린샷을 열람했습니다. savinqkr 계정 연결에서는 편집 접근 오류가 났지만 다른 연결에서 정상 열람했습니다. 원본은 수정하지 않았습니다.

- 밝은 회청 작업 영역, 넓은 표지·종이·중앙 제본, 상단 복귀·제목, 하단 탐색 구도를 반영했습니다.
- 원본은 moodbook/Inter, 구현은 기존 FOLINA 헤더/시스템 글꼴입니다.
- 원본 월간 달력·스티커·사진·테이프는 저장 내용이 아니므로 표시하지 않습니다. 월간 템플릿 제공을 새로 확정하지 않습니다.
- 원본 종이 비율을 고정 복제하지 않고 실제 저장된 A4 및 페이지별 크기를 존중합니다. 원본 편집 버튼은 준비 중 안내로 바꿉니다. 목차·책갈피 목록은 시스템 시트로 제공합니다. 썸네일 별도 패널은 제외합니다.
- 링 그림자 SVG 다운로드가 HTTP 403으로 실패하여 기존 SwiftUI 금속 링을 재사용했습니다. 원본 에셋과 픽셀 일치를 주장하지 않습니다.
- 하드커버·일반 제본과 세로/좁은 창의 세부 렌더링은 이번 요구사항과 기존 컴포넌트를 바탕으로 구현했으며 해당 변형의 별도 Figma 프레임을 확인한 것은 아닙니다.

저장/호환성은 [데이터 모델](../architecture/data-model.md), 검증 절차는 [읽기 검증](../development/reading-verification.md)을 참고합니다.

## 5차 변경

이전 준비 중 버튼을 실제 선택 페이지의 편집 진입으로 바꿨습니다. 복귀 시 저장 원본을 다시 읽어 속지 위에 표시합니다. 표시용 이미지만 만들고 읽기에서 원본을 수정하지 않습니다. [편집 명세](editor-spec.md)를 참고합니다.
