## 이번 책장 홈의 탐색 범위

Figma v5 책장 홈의 사이드 항목(내 다이어리·무료 굿즈·내 굿즈·설정)을 확인했습니다. 현재 내 다이어리를 선택 표시하고, 다른 항목을 누르면 준비 중 안내를 제공합니다. 다이어리 읽기·편집 화면으로의 이동은 구현하지 않습니다. 2차 개발에서는 책장의 생성 버튼에서 생성 옵션 화면으로 이동하고 뒤로 가기로 책장에 복귀합니다. 실제 생성·저장은 없으며 복귀하면 초안을 폐기합니다. 전체 IA와 화면 전환 정책을 확정한 것은 아닙니다.

## 책장 사이드바 확장 — 2026-10-16 사용자 요청

내 다이어리·무료 굿즈·내 굿즈·마켓·설정 순서로 메뉴를 표시합니다. SF Symbols의 책·선물·쌓인 카드·쇼핑백·톱니바퀴 아이콘을 각각 사용합니다. 마켓의 실제 상품 목록·구매는 구현하지 않고 다른 미구현 메뉴와 동일하게 준비 중 안내만 표시합니다.

상단 사이드바 버튼으로 펼침(208pt, 아이콘+이름)과 접힘(68pt, 아이콘만)을 전환합니다. 접힌 상태도 접근성 이름·현재 메뉴 선택 표시·포인터 도움말을 유지합니다. 상태는 책장 화면에서 보유하여 생성 화면 왕복 시 유지하며 앱 재실행 시 초기화합니다. 폭 600pt 이상에서 제공하고 더 좁은 창에서는 책장 영역을 우선합니다. 기존 900pt 기준보다 낮춰 iPad 세로 화면에서도 사용합니다. 세로 공간이 부족하면 메뉴를 스크롤합니다.
