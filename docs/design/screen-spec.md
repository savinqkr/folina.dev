# 화면 명세

- 원본/근거: [Figma](https://www.figma.com/design/FFQxwcgxtazngCK8Sp26hv/Untitled) · [기능 명세](https://app.notion.com/p/3f91e7915bce81f89817c482350c29da)
- 확인일: 2026-10-15 (한국 시간, 외부 원본은 접근 시도일)
- 문서 상태: 자료 확인 필요

최신 MVP UX 디자인 페이지에서 v5로 수정된 화면을 우선 참고하라는 사용자 지시가 있습니다. 실제 페이지와 v5 화면은 아직 열람하지 못했습니다.

화면 목록, 화면별 레이아웃, 입력, 빈 상태·로딩·오류 상태, 인터랙션, 적응형 레이아웃은 자료 확인 필요입니다. 구현된 초기 화면은 [아키텍처 개요](../architecture/overview.md#확인된-현재-구현)를 참고합니다.

추후 확인 시 화면명과 Figma 프레임/노드 링크를 기록하고 [기능 명세](../product/feature-spec.md) 및 [탐색 구조](navigation.md)에 연결합니다.
