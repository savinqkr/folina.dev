## 사용자 요청으로 추가한 표지 표현

2026-10-15에 사용자가 실행 화면을 제공하며 실물 다이어리 같은 입체감을 요청했습니다. 아래는 Figma v5 원본과 구분하는 사용자 요청 기반의 디자인 변경입니다. Figma 원본은 수정하지 않았습니다.

- 표지·종이 묶음·뒷표지를 분리하고 종이 낱장 단면과 가까운/먼 그림자를 겹칩니다.
- 약한 원근과 기울기, 가장자리의 빛·음영으로 두께를 표현합니다.
- 링바인더: 여섯 개의 속이 빈 금속 링, 광택·그림자·펀칭 구멍, 종이 제목 라벨을 적용합니다.
- 양장: 천 결, 둥근 책등과 눌린 홈, 리본 책갈피를 적용합니다. 후속 요청으로 표지 문구는 제거했습니다.
- 일반 제본: 미세한 종이 질감, 얇은 책등, 테두리 장식과 탄성 밴드를 적용합니다. 후속 요청으로 표지 문구는 제거했습니다.
- 세이지·슬레이트 블루·로즈 색상과 카드의 192×287pt 표지 영역을 유지합니다. 카드 밖 제목·접근성 설명을 그대로 제공합니다.

장식은 SwiftUI 도형과 결정적인 Canvas 패턴으로 그립니다. 다운로드·새 이미지 리소스·외부 라이브러리를 추가하지 않습니다. 실제 시뮬레이터 렌더링 확인은 Mac에서 필요합니다.

## 사용자 요청으로 변경한 표지 문구와 카드 정렬

- 첫 번째 샘플(링바인더)의 `사계절의 기록` 제목은 나눔손글씨 펜으로 표시합니다. 기존 라벨의 작은 영문·권호 문구는 유지합니다.
- 첫 번째를 제외한 여섯 샘플은 제목·영문·연도 문구를 표시하지 않습니다. 표지 테두리·재질·제본 장식은 유지합니다.
- 다이어리 아래 제목과 설명은 전체 그리드 칸이 아닌 표지 영역 너비 192pt에 맞춰 가운데 정렬합니다. 여러 줄도 가운데 정렬합니다.
- 손글씨 제목은 장식 영역이며, 카드의 접근성 설명으로 동일한 제목과 제본 정보를 제공합니다.

## 헤더 브랜드 아이콘

사용자의 깃털 아이콘 배치 요청에 따라 헤더의 `▤` 문자를 제거하고, 앱 이름 왼쪽에 `HeaderLogo` 이미지를 30×30pt로 배치합니다. 이름과 간격은 8pt이며 원래 비율과 색상을 유지합니다. 장식 이미지는 VoiceOver에서 제외하고 앱 이름은 텍스트로 제공합니다.

2026-10-16 사용자 피드백에 따라 밝은 사각 배경이 들어 있던 헤더 리소스를 교체했습니다. 첨부 깃털 이미지를 기반으로 이미지 편집 도구에서 생성한 투명 PNG를 `HeaderLogo.imageset/feather.png`에 적용했습니다. 첨부 원본 파일의 직접 복사는 아니며, 헤더 크기와 배치는 유지합니다. 홈 화면 앱 아이콘 파일은 변경하지 않았습니다. 알파 채널은 확인했으며 실제 iPad 렌더링은 Mac에서 확인해야 합니다.

## 2026-10-16 — 책장 샘플 영역 제거와 좌우 여백 통일

사용자 후속 요청으로 홈의 ‘표지 샘플 보기 · 저장되지 않는 예시’ 영역을 제거했습니다. 실제 저장된 다이어리와 생성 진입점만 표시합니다. 샘플 정의·기존 표지 컴포넌트는 유지하며 사용자 저장 데이터는 변경하지 않습니다.

책장 콘텐츠의 1200pt 최대 폭 제한·중앙 정렬을 제거하고 실제 사용 가능한 콘텐츠 폭에 맞췄습니다. 책장과 생성 화면 모두 `FolinaTheme.Spacing.horizontalPage(width:)`를 사용하여 사용 가능한 폭 600pt 이상에서는 좌우 35pt, 미만에서는 16pt를 적용합니다. 책장 사이드바가 표시되면 그 오른쪽 콘텐츠 영역을 기준으로 합니다. 실제 화면 비교는 Mac에서 확인해야 합니다.

## 2026-10-16 — 책장 가로·세로 표지 구분

저장된 다이어리 생성 옵션의 방향을 책장 표시 모델에 전달합니다. 세로형은 기존 긴 표지, 가로형은 넓고 낮은 표지로 그리며 제본·종이 단면·장식도 높이에 맞춥니다. 링은 가로형에서 3개로 줄이고 표지 글자는 회전하지 않습니다. 카드 설명과 접근성 이름에 ‘가로형/세로형’을 표시하며 제목 기준선은 유지합니다. 저장 데이터와 읽기 페이지 방향은 변경하지 않습니다. 실제 렌더링 검증은 Mac에서 필요합니다.

## 2026-10-16 — 가로형 표지 확대와 세로 중앙 정렬

사용자 실행 화면 피드백에 따라 책장 가로형 표지를 비율 그대로 15% 확대하고 공통 높이 287pt 영역의 세로 중앙에 배치합니다. 카드 폭과 그리드 최소 폭은 224pt로 맞춰 확대 표지의 공간을 확보했습니다. 세로형 표지 크기는 유지하며 제목·설명은 공통 표지 영역 아래에 표시합니다. Swift 구문·diff 검사는 통과했으며 실제 화면 렌더링은 Mac에서 확인해야 합니다.
