## 확정 범위와 구현

읽기에서 현재 선택 UUID의 페이지를 전체 화면 편집기로 전달합니다. 펜·형광펜·벡터 지우개, 색상, 도구별 굵기, 실행 취소·다시 실행, 저장 상태와 재시도를 제공합니다. 손가락 필기를 켜면 Pencil과 터치 모두 필기하며, 끄면 Pencil 전용 필기와 손가락 스크롤을 사용합니다. 페이지 맞춤 기준 100–300% 버튼 확대·축소를 제공합니다. 핀치·회전 제스처·무한 캔버스는 미구현입니다. 확대와 이동은 보기 상태이며 저장 좌표를 변경하지 않습니다.

종이 무늬와 필기는 동일한 페이지 좌표에서 함께 확대합니다. 편집 대상은 한 페이지이며 페이지 이동은 저장 성공 후 읽기로 복귀하여 선택한 뒤 다시 편집하는 흐름입니다. 다른 페이지로 즉시 이동하는 편집기 내부 UI는 없습니다.

읽기 복귀 버튼은 저장 성공을 기다리고 실패하면 편집기를 유지합니다. 대화형 닫기는 차단합니다. 불러오기 실패 시 필기를 막고 재시도 또는 읽기 복귀를 제공합니다. 저장 실패 시 드로잉과 실행 취소 기록은 메모리에 남지만 저장 완료로 표시하지 않습니다.

## 원본 확인과 차이

두 Figma 프레임의 실제 스크린샷(1180×820)을 연결 도구로 확인했습니다. 흰색 상단 도구 영역, 도구 선택 강조, 아이콘, 회청 작업 배경, 저장 상태, 넓은 종이 작업 영역을 반영합니다. 원본의 moodbook 로고와 색상 도구 그림은 기존 FOLINA 헤더·테마와 SF Symbols로 대체합니다. 픽셀 일치는 검증하지 않았습니다.

원본은 펼침·달력·사진·스티커·이동 가능한 레이어 패널을 표현하지만 이번에는 선택한 실제 페이지의 속지를 사용합니다. 레이어 패널과 미구현 도구 버튼은 표시하지 않습니다. 툴바와 캔버스를 분리해 후속 도구·패널 추가 지점을 유지합니다. 손가락 필기 전환과 확대 버튼은 이번 입력 충돌 방지를 위한 구현 선택이며 원본의 확정 세부 정책이라고 주장하지 않습니다.

Notion EDT-01의 터치 줌·회전·호버 전체, EDT-03 다중 레이어, BRU 고급 브러시와 로그인·동기화는 이번 요청의 기본 필기 범위에 포함하지 않습니다. 기본 입력 특성은 PencilKit과 기기 지원에 의존하며 커스텀 필압 곡선·브러시 안정화 설정은 제공하지 않습니다. 원본은 수정하지 않았습니다.

저장·좌표·엔진 확장 설명은 [필기 아키텍처](../architecture/ink-editor.md), 검증은 [편집기 검증](../development/editor-verification.md)을 참고합니다.

## 6차 확장

선택·텍스트·사진 도구와 공통 객체 속성 영역을 추가했습니다. 입력 모드, 원본 디자인 차이, 페이지 관리 진입은 [6차 화면 명세](page-decoration-spec.md)를 참고합니다. 위 5차 제외 목록 중 텍스트·사진과 페이지 관리는 이번 범위에서 구현했으며 고급 레이어 패널은 계속 제외합니다.
