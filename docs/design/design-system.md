## 이번 화면에 적용한 스타일

[FolinaTheme.swift](../../FOLINA/DesignSystem/FolinaTheme.swift)에서 색상·타이포그래피·간격·기본 버튼 스타일을 관리합니다. 기존 공통 컴포넌트나 외부 라이브러리는 없습니다.

| 역할 | Figma에서 확인한 값 |
|---|---|
| 기본 배경 / 흰 표면 | `#F8F9FB` / `#FFFFFF` |
| 컬렉션 / 선택 배경 | `#E8EDF1` / `#EDF1F4` |
| 본문 / 보조 글자 | `#20252A` / `#7D8590` |
| 세이지 / 슬레이트 블루 / 로즈 표지 | `#BBCDC5` / `#C5D4E0` / `#D7C3CD` |
| 주요 간격 | 8 / 16 / 24 / 35 / 56pt |

Figma는 Inter를 사용합니다. 사용자가 추천 선택을 위임하여 iPad 기본 시스템 서체를 적용했습니다. 화면 제목·본문·캡션은 SwiftUI 의미 기반 글자 스타일로 사용자 글자 크기를 따릅니다. 표지의 작은 장식 문구는 고정 크기이며 카드의 접근성 설명으로 내용을 제공합니다.

밝은 디자인을 유지하도록 책장 홈은 라이트 모드로 표시합니다. 다크 모드 디자인은 이번 범위에 포함하지 않습니다. 공통 버튼의 터치 높이는 44pt 이상으로 적용했습니다.

이 값은 확인한 책장 홈 범위의 토큰이며, 전체 제품 디자인 시스템을 확정한 것은 아닙니다.

## 표지 재질과 입체감

사용자의 실물 표현 개선 요청에 따라 `DiaryCoverView` 안에서 종이·천 결·금속·표지 가장자리의 광택과 접촉 그림자를 구성합니다. 광원은 왼쪽 위에서 들어오는 방향으로 통일합니다. 재질 패턴은 좌표로 계산하여 다시 그려도 바뀌지 않습니다.

책등·펀칭 구멍·링·리본·밴드는 장식이며 별도 조작 기능이 없습니다. 링바인더의 제목은 나눔손글씨 펜을 사용합니다. 나머지 여섯 표지에는 문구를 표시하지 않으며 화면의 제목·본문은 기존 시스템 스타일을 유지합니다. Figma 원본과의 변경 근거는 [화면 명세](screen-spec.md#사용자-요청으로-추가한-표지-표현)에 기록합니다.

## 한글 손글씨 리소스

사용자의 손글씨 요청에 따라 [나눔손글씨 펜](https://github.com/google/fonts/tree/main/ofl/nanumpenscript)을 `FOLINA/Fonts/NanumPenScript-Regular.ttf`에 포함했습니다. 파일에서 확인한 PostScript 이름은 `NanumPen-Regular`이며, `FolinaTheme.Typography.handwrittenCover`가 CoreText로 한 번 등록합니다. Xcode 기존 동기화 폴더를 통해 앱 리소스로 포함하며 다운로드 없이 동작합니다. 기본 크기 27pt에 `.title2` 기준 글자 크기 조절을 적용합니다.

글꼴은 수정하지 않았고 [SIL Open Font License 원문](../../FOLINA/Fonts/OFL.txt)을 함께 배포합니다. 외부 라이브러리를 추가하지 않았습니다. 실제 앱 번들 포함·손글씨 렌더링은 Mac에서 확인해야 합니다.

## 추가 샘플 디자인

사용자의 일곱 권 확장 및 다른 디자인 요청으로 코코아(`#987566`)·버터(`#E5D8AB`)·라벤더(`#C9C5D7`)·크라프트(`#C7AE8D`)를 표지 전용 색상으로 추가했습니다. 기존 세 권의 색상·스타일은 유지합니다.

추가 디자인은 `DiaryCoverDecoration`에서 분리합니다. 가죽 랩의 박음질·스냅, 윈도형 린넨의 식물 장식, 크라프트의 메모 포켓을 그립니다. 스프링 제본은 `DiaryCoverView`의 별도 제본 표현으로 구성합니다. 모든 장식은 제목 없는 SwiftUI 도형이며 Figma 원본의 확정 디자인이 아닌 사용자 요청에 따른 구현입니다.
