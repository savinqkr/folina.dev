## 확정 요구사항 — 이번 사용자 요청

| 기능 | 수용 기준 |
|---|---|
| 첫 화면 | 앱 시작 시 책장 홈 제목과 샘플 7개 표시 |
| 실물 표지 | 링바인더·양장·일반 제본을 시각적으로 구분 |
| 생성 진입점 | 새 다이어리 만들기 버튼에서 생성 옵션 화면으로 이동 |
| 샘플 분리 | 표시 전용 샘플을 사용자 저장 데이터와 분리 |
| 레이아웃 | iPad 가로·세로와 좁은 창에서 스크롤하여 샘플 열람 가능 |

범위와 미구현 항목은 [MVP 범위](mvp-scope.md), 시각적 세부사항은 [화면 명세](../design/screen-spec.md)를 참고합니다.

Notion [기능 명세 원본](https://app.notion.com/p/3f91e7915bce81f89817c482350c29da)은 본문 미확인입니다. 위 표는 이번 사용자 요청의 범위이며 전체 제품 기능 명세가 아닙니다.

## 2차 개발 — 사용자 요청으로 확정

이름·기록 방식 3종·제본 3종·표지 색상·표지 스타일·속지 4종·페이지 방향을 선택하고 실시간 미리보기에 반영합니다. 기록 방식과 외형은 독립적입니다. 최종 버튼은 저장 미지원 안내를 표시하며 생성 성공으로 표시하지 않습니다. 확정 선택지·검증 기준은 [생성 화면 명세](../design/creation-spec.md)에 모아 관리합니다.

## 4차 개발 — 읽기와 탐색

실제 저장 다이어리 열기, 제본별 외형, 저장 페이지 표시, 창 크기별 1/2페이지, 경계 이동·목차·UUID 책갈피 저장을 추가했습니다.

상세 내용은 [읽기 명세](../design/reading-spec.md)와 [읽기 검증](../development/reading-verification.md)을 참고합니다.
