# 기능 명세

- 원본/근거: [기능 명세](https://app.notion.com/p/3f91e7915bce81f89817c482350c29da)
- 확인일: 2026-10-15 (한국 시간, 외부 원본은 접근 시도일)
- 문서 상태: 자료 확인 필요

확정된 기능 목록·입력·출력·예외 처리·수용 기준은 원본 확인 후 기록합니다. 디지털 다이어리라는 제품 설명만으로 필기, 스티커, 동기화 등의 구체 기능을 확정하지 않습니다.

현재 구현은 [아키텍처 개요](../architecture/overview.md#확인된-현재-구현)를 참고합니다. 현재 구현과 향후 요구사항은 구분합니다.

## 제안사항

원본 열람 후 기능별로 원본 위치, 동작, 예외, 수용 기준, 관련 화면을 정리하는 방식을 제안합니다. 아직 확정된 기능 명세는 아닙니다.
