## 이번 개발 범위 — 사용자 요청으로 확정

기존 Xcode 프로젝트에서 SwiftUI 기본 구조, 디자인 토큰과 기본 컴포넌트, 샘플 7개의 책장 홈을 구현합니다. 기존 기기군, 최소 iOS/iPadOS 18.2, 테스트 타깃을 유지합니다. 외부 라이브러리를 추가하지 않습니다.

다이어리 생성·읽기·편집·저장, 인증·서버·결제·동기화·브러시 엔진은 구현하지 않습니다. 실제 사용자 데이터는 취급하지 않습니다.

전체 제품의 MVP 범위·출시 조건은 [MVP 정책 원본](https://app.notion.com/p/3f91e7915bce8177a7fcf5b86d220de7)의 본문 확인이 필요합니다. 이번 범위를 전체 MVP로 해석하지 않습니다.

## 2차 개발 범위 — 2026-10-16

위 책장 초기 범위에 생성 옵션 화면·실시간 표지/속지 미리보기·화면 이동을 추가했습니다. 영구 저장·실제 생성·책장 등록·날짜형 페이지 생성은 제외합니다. 이름과 옵션은 화면을 나가면 폐기합니다. 상세 선택지와 디자인 차이는 [생성 화면 명세](../design/creation-spec.md)를 참조합니다.

## 4차 개발 범위

이전 단계의 제외 범위 중 읽기·페이지 탐색·로컬 책갈피를 이번 요청으로 구현했습니다. 필기·실제 편집·페이지 추가/삭제·미디어 배치·동기화·로그인·결제·검색·외부 공유는 제외합니다.

상세 내용은 [읽기 명세](../design/reading-spec.md)와 [읽기 검증](../development/reading-verification.md)을 참고합니다.
