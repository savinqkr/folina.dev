## 2026-10-15 — 문서 관리 및 개발 협업 기반 추가

- `docs/`에 제품·디자인·아키텍처·개발 문서 구조를 추가했습니다.
- 원본을 Source of Truth로 유지하고 GitHub는 확정 사항의 참조용 명세로 관리하도록 기록했습니다.
- 원본 링크 8개와 네트워크 프록시 403 접근 결과를 기록했습니다. 본문이 미확인인 문서는 자료 확인 필요로 표시했습니다.
- 현재 앱 구조·iPad 지원 설정과 Linux의 빌드/테스트 제약을 저장소 확인 결과로 기록했습니다.
- 루트 `AGENTS.md`에 이후 개발 작업의 문서 참조·질문·PR 검토 규칙을 추가했습니다.
- 커밋 메시지를 깃모지·작업 종류·한국어 작업 설명 형식으로 작성하도록 규정했습니다.
- 브랜치 접두사별 PR 깃모지, 한국어 PR 설명, `savinqkr` 담당자 지정과 작업별 라벨 규칙을 추가했습니다.
- 모든 PR을 GitHub 프로젝트 `Folina`에 연결하고 적용 결과를 확인하도록 규정했습니다.
- PR 설명을 이모지가 붙은 5개 항목으로 통일하고 스크린샷 표기·검증 결과 작성 규칙과 PR 템플릿을 추가했습니다.
- SwiftUI 앱 코드, 테스트 코드, Xcode 프로젝트 설정은 변경하지 않았습니다.

커밋·PR 생성이나 병합 상태는 이 기록만으로 완료를 의미하지 않으며 실제 GitHub 결과로 확인합니다.
