# 편집기 검증

- 원본/근거: 5차 개발 요청 및 현재 구현
- 확인일: 2026-10-16 (한국 시간)
- 문서 상태: Linux 정적 검사 완료 / Xcode 및 실제 iPad 검증 미실행

## 자동 테스트 작성

`PageInkTests.swift`에 페이지/다이어리 격리, 실제 PKDrawing의 디스크 재로딩과 빈 드로잉 저장, ID·버전·좌표 검증, 기존 문서 호환, 손상 파일 보존, 저장 실패와 재시도, 연속 변경 디바운스, 편집 종료 즉시 저장, 불러오기 실패 시 쓰기 방지를 작성했습니다. Apple SDK가 필요하므로 실행하지 않았습니다. 기존 SwiftData·읽기 테스트도 실행하지 않았습니다.

Linux에서는 Swift tree-sitter 구문 검사와 diff 공백 오류·문서 링크 검사를 수행합니다. 이는 Swift 타입 검사·앱 빌드·기능 테스트를 대체하지 않습니다.

## Mac Xcode 및 실제 iPad 확인

1. Xcode에서 FOLINA 프로젝트/스킴과 사용 가능한 iPadOS 18.2 이상 대상을 확인하고 빌드 및 전체 테스트를 실행합니다. 기존 저장 문서·책갈피가 유지되는지도 확인합니다.
2. 두 다이어리를 만들고 읽기에서 원하는 페이지를 선택해 편집합니다. 여러 페이지 테스트는 기존 테스트 fixture를 활용합니다. 생성 UI는 여전히 첫 페이지 1개입니다.
3. 실제 Pencil로 필압·기울기를 바꾸며 펜/형광펜, 색상·굵기, 벡터 지우개를 확인합니다. 형광펜 겹침과 실제 불투명도는 PencilKit 렌더링으로 확인합니다.
4. 획 여러 개 → 실행 취소 → 다시 실행 → 저장 → 읽기로 돌아가 동일한 획인지 확인합니다. 저장으로 Undo 기록이 초기화되지 않고 새 편집 세션에서는 초기화되는지 확인합니다.
5. 연속 필기 중 저장 대기/저장 중/저장됨을 확인하고 획 직후 읽기 복귀·다른 페이지 선택·재편집 시 유실과 다른 페이지 혼입이 없는지 확인합니다.
6. 앱 비활성·백그라운드·재실행 후 다시 편집해 기존 획을 지울 수 있는지 확인합니다. 저장 완료 전 강제 종료와 완료 후 종료를 구분해 마지막 변경 보존 범위를 기록합니다.
7. 무지·줄·모눈·도트, 가로/세로 종이에서 모서리·무늬 교차점에 표시한 뒤 기기 회전·Split View·Stage Manager·100–300% 확대 시 일치하는지 확인합니다. 읽기/편집에서 속지와 필기 정렬도 비교합니다.
8. 손가락 필기를 켜서 터치 입력, 끄고 Pencil 필기+손가락 스크롤을 확인합니다. 확대된 캔버스의 스크롤과 Pencil 팜 리젝션 충돌을 실제 iPad에서 확인합니다.
9. 저장 실패 주입 시 오류가 표시되고 편집 내용·Undo 기록이 유지되며 읽기 복귀가 막히는지 확인합니다. 재시도 성공 후 복귀합니다. 손상 파일/미지원 버전은 편집 금지와 원본 보존을 확인합니다.
10. 장시간 다량 필기에서 메모리, 원본 파일 크기, 직렬화/저장 지연과 읽기 이미지 생성 시간을 측정합니다. Pencil 기종별 지원 범위와 Figma 대비 실제 스크린샷을 PR에 첨부합니다.

미구현: 핀치/회전 제스처, 다중 레이어, 커스텀 브러시, 내부 페이지 이동, 충돌 보호 사본·백업/동기화. 검증 결과를 확정 정책으로 추정하지 않습니다.
